# Документация разработчика

## Наименование программы

**Color Converter** — веб-приложение для преобразования цветов между различными цветовыми пространствами (RGB, XYZ, LAB) с использованием HTML, CSS и JavaScript.

---

## Область применения

Программа предназначена для **визуализации** и **конвертации** значений цвета между различными цветовыми пространствами, такими как RGB, XYZ и LAB. Она может быть полезна для дизайнеров, разработчиков и студентов, изучающих цветовые модели.

---

## Назначение программы

Программа выполняет следующие задачи:

1. Преобразование цвета между цветовыми пространствами:
   - **RGB (Red, Green, Blue)**.
   - **XYZ (CIE 1931)**.
   - **LAB (CIE LAB)**.
2. Отображение выбранного или преобразованного цвета.
3. Ввод данных вручную или выбор цвета с помощью встроенного цветового селектора.
4. Предупреждение пользователя о выходе значений за допустимые пределы.

---

## Функциональные возможности

1. **Выбор цвета**:
   - Пользователь может выбрать цвет с помощью встроенного селектора цвета (`input type="color"`).
   - Ввод значений вручную в поля RGB, XYZ или LAB.

2. **Автоматическая конвертация**:
   - При изменении значений в одной модели автоматически пересчитываются значения в других моделях.

3. **Отображение цвета**:
   - Выбранный или преобразованный цвет отображается в блоке `.color-display`.

4. **Предупреждения**:
   - Если значения выходят за допустимые пределы (например, RGB вне диапазона 0–255), отображается предупреждение.

## Структура программы

### Основные элементы

1. **HTML**:
   - Структура пользовательского интерфейса:
     - Поля ввода для RGB, XYZ, LAB.
     - Селектор цвета (`<input type="color">`).
     - Блок для отображения цвета.
     - Предупреждение о недопустимых значениях.

2. **CSS**:
   - Стилизация интерфейса:
     - Центрирование элементов.
     - Стили для блока отображения цвета.
     - Скрытие/отображение предупреждений.

3. **JavaScript**:
   - Логика конвертации между цветовыми пространствами.
   - Обработка событий ввода и обновления интерфейса.

---

### Основные методы JavaScript

#### Конвертация цветов

1. **Преобразование HEX → RGB**:
   - Функция `hexToRgb(hex)` преобразует шестнадцатеричный цвет в RGB.

2. **Преобразование RGB → XYZ**:
   - Функция `rgbToXyz(r, g, b)` преобразует значения RGB в цветовое пространство XYZ.

3. **Преобразование XYZ → RGB**:
   - Функция `xyzToRgb(x, y, z)` преобразует значения XYZ обратно в RGB.

4. **Преобразование XYZ → LAB**:
   - Функция `xyzToLab(x, y, z)` преобразует значения XYZ в LAB.

5. **Преобразование LAB → XYZ**:
   - Функция `labToXyz(l, a, b)` преобразует значения LAB обратно в XYZ.

#### Обновление интерфейса

1. **Обновление из RGB**:
   - Функция `updateDisplayFromRgb()`:
     - Читает значения RGB.
     - Конвертирует их в XYZ и LAB.
     - Обновляет интерфейс.

2. **Обновление из XYZ**:
   - Функция `updateDisplayFromXyz()`:
     - Читает значения XYZ.
     - Конвертирует их в RGB и LAB.
     - Обновляет интерфейс.

3. **Обновление из LAB**:
   - Функция `updateDisplayFromLab()`:
     - Читает значения LAB.
     - Конвертирует их в RGB и XYZ.
     - Обновляет интерфейс.

4. **Обновление из селектора цвета**:
   - Функция `updateDisplayFromPicker()`:
     - Читает выбранный цвет в формате HEX.
     - Конвертирует его в RGB.
     - Обновляет интерфейс.

## Инструкция по установке и запуску

### Требования

- Современный браузер с поддержкой HTML5, CSS3 и JavaScript.

### Установка

1. Сохраните код в файл с расширением `.html`, например, `color_converter.html`.
2. Откройте файл в браузере.

---

## Инструкция пользователя

1. **Выбор цвета**:
   - Откройте приложение в браузере.
   - Выберите цвет через встроенный селектор или введите значения вручную.

2. **Просмотр результата**:
   - Цвет отобразится в блоке `.color-display`.
   - Значения в других цветовых пространствах пересчитаются автоматически.

3. **Исправление ошибок**:
   - Если вы ввели некорректные значения, исправьте их, чтобы они соответствовали допустимым пределам.

---

## Обработка ошибок

- Если значения выходят за пределы допустимого диапазона:
  - RGB (0–255)
  - XYZ (зависит от модели)
  - LAB (зависит от модели)
- Программа автоматически ограничивает значения до допустимых пределов.
- Отображается предупреждение в блоке `#warning`.
