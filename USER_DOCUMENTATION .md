# Пользовательская документация

## 1. Введение

Программа **"Color Converter"** предназначена для преобразования цветов между различными цветовыми пространствами: RGB, XYZ и LAB. Приложение позволяет пользователю вводить значения цвета в одном цветовом пространстве, автоматически конвертируя их в другие пространства, а также отображать соответствующий цвет в реальном времени.

---

## 2. Системные требования

### Программные требования:
- Любой современный веб-браузер (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
- Поддержка JavaScript и HTML5.

### Аппаратные требования:
- Минимум 512 МБ оперативной памяти.
- Разрешение экрана: не менее 1024x768 пикселей.

---

## 3. Установка

Приложение не требует установки. Оно запускается в веб-браузере.

### 3.1 Запуск приложения

1. Скачайте HTML-файл программы или скопируйте его код.
2. Откройте файл в любом современном браузере, дважды кликнув на него или перетащив в окно браузера.

---

## 4. Использование приложения

### 4.1 Основной интерфейс

Приложение состоит из следующих элементов:
1. **Цветовой дисплей**: отображает текущий цвет в прямоугольной области.
2. **Выбор цвета**: встроенный цветовой селектор для выбора цвета в формате HEX.
3. **Панели ввода**:
   - **RGB**: ввод значений красного (R), зеленого (G) и синего (B) цветов.
   - **XYZ**: ввод значений в цветовом пространстве XYZ.
   - **LAB**: ввод значений в цветовом пространстве LAB.
4. **Предупреждение**: отображается, если введенные значения выходят за допустимые пределы.

---

### 4.2 Выбор цвета через селектор

1. Используйте встроенный цветовой селектор (элемент `<input type="color">`).
2. После выбора цвета значения RGB обновятся автоматически.
3. Цвет будет отображен в блоке **"Цветовой дисплей"**.
4. Значения XYZ и LAB пересчитаются и отобразятся в соответствующих полях.

---

### 4.3 Ввод значений вручную

#### RGB:
1. Введите значения для красного (R), зеленого (G) и синего (B) цветов в диапазоне от 0 до 255.
2. Цвет будет автоматически отображен в блоке **"Цветовой дисплей"**.
3. Значения XYZ и LAB пересчитаются автоматически.

#### XYZ:
1. Введите значения для X, Y и Z в допустимых диапазонах:
   - X: от 0 до 95.05.
   - Y: от 0 до 100.
   - Z: от 0 до 108.89.
2. Цвет будет преобразован в RGB и LAB, с автоматическим отображением результата.

#### LAB:
1. Введите значения для L, a и b в допустимых диапазонах:
   - L: от 0 до 100.
   - a: от -128 до 127.
   - b: от -128 до 127.
2. Цвет будет преобразован в RGB и XYZ, с автоматическим отображением результата.

---

### 4.4 Предупреждения

При вводе значений, выходящих за допустимые пределы, приложение отображает предупреждение **"Warning: Color conversion out of range. Values have been clamped."**. Это означает, что значения были автоматически скорректированы до ближайших допустимых границ.

---

## 5. Пример использования

### Пример 1: Выбор цвета через селектор
1. Нажмите на цветовой селектор.
2. Выберите, например, красный цвет (#FF0000).
3. Значения RGB обновятся: R = 255, G = 0, B = 0.
4. Цвет будет отображен в блоке **"Цветовой дисплей"**.

### Пример 2: Ввод значений RGB
1. Введите значения R = 0, G = 255, B = 0.
2. Цвет (зеленый) будет отображен в блоке **"Цветовой дисплей"**.
3. Значения XYZ и LAB пересчитаются автоматически.

### Пример 3: Ввод значений LAB
1. Введите значения L = 50, a = 0, b = 0.
2. Цвет будет преобразован в RGB и XYZ, а результат отобразится в блоке **"Цветовой дисплей"**.
